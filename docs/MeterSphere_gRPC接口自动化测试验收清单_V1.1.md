# 1. 测试数据准备

| **数据项**         | **说明**                                                        | **预期**                     |
|--------------------|-----------------------------------------------------------------|------------------------------|
| helloworld.proto   | 无 import，包含 Greeter/SayHello Unary                          | 用于基础调试                 |
| user_service.proto | 包含 string/int32/enum/repeated/nested 字段                     | 用于模板、AI、断言、变量提取 |
| streaming.proto    | 包含 Server/Client/Bidi Streaming Method                        | V1.0 展示但置灰              |
| import_error.proto | 包含业务 import                                                 | V1.0 提示不支持 import       |
| gRPC 测试服务      | plaintext，支持 Unary，返回 OK/INVALID_ARGUMENT/UNAUTHENTICATED | 用于成功和异常验证           |
| Metadata 模板      | authorization: Bearer \${token}, tenant-id: \${tenant_id}       | 用于变量和脱敏验证           |
| AI 模型配置        | 系统设置或个人中心已开启模型                                    | 用于 AI 生成用例验证         |
| 本地执行环境       | 如启用本地执行，task-runner 地址检测通过                        | 用于本地执行验证             |
