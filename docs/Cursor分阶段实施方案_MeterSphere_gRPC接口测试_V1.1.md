# 1. 全局 Cursor 规则

你正在 MeterSphere 社区版中增加 gRPC 协议接口测试能力。

必须遵守：

1\. 不做孤立 gRPC 工具页，必须融入现有接口测试模块。

2\. 不重写 HTTP 现有功能；所有旧数据默认 HTTP。

3\. UI 必须复用 MeterSphere 已有组件、表格、Tab、弹窗、编辑器、AI 生成流程。

4\. AI 相关能力必须复用现有模型设置、AI 生成、同步用例流程。

5\. 每阶段只改当前阶段范围，先列影响文件，再修改。

6\. 后端、前端、数据库、测试均需有验证步骤。

7\. 涉及数据库必须提供迁移和回滚说明。

8\. 每阶段结束必须输出：改动清单、验证结果、已知风险、下一步建议。
